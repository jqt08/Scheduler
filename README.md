# Shift Timeline Maker

A static HTML/CSS/JavaScript shift scheduler designed for GitHub Pages.

## Features
- Multi-month date ranges
- Multiple teams
- Click-and-drag working-day selection
- Unselected dates become rest days
- Default and special shifts
- Overnight shifts spill onto the next calendar row with the same color
- SVG timeline download
- JSON schedule export

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `app.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then Save.
6. GitHub will show the public Pages address after deployment.

No Python server, Streamlit, or Colab is required.
